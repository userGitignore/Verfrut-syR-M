Manual SEO Técnico: Elementos <head> para Indexación Orgánica

Aplicación: Estas modificaciones deben implementarse en todas las páginas del sitio web, no solo en index.html. Cada página es una entrada de indexación independiente.

1. Metadatos Fundamentales

<!-- Título (obligatorio) - máximo 60 caracteres -->
<title>Título Descriptivo | Marca</title>

<!-- Descripción (obligatorio) - máximo 160 caracteres -->
<meta name="description" content="Descripción atractiva que invite al clic">

<!-- Codificación de caracteres -->
<meta charset="UTF-8">

<!-- Idioma (atributo en etiqueta html) -->
<html lang="es">

2. Indexación y Rastreo

<!-- Control de indexación (por defecto: index, follow) -->
<meta name="robots" content="index, follow">

<!-- Variante específica para Google -->
<meta name="googlebot" content="index, follow">

<!-- URL canónica (obligatorio si hay duplicados o parámetros URL) -->
<link rel="canonical" href="https://www.ejemplo.com/pagina">

3. Open Graph (Redes Sociales + SEO Indirecto)

<meta property="og:title" content="Título para compartir">
<meta property="og:description" content="Descripción para redes sociales">
<meta property="og:url" content="https://www.ejemplo.com/pagina">
<meta property="og:type" content="website"> <!-- o article, product -->
<meta property="og:image" content="https://www.ejemplo.com/imagen.jpg">

4. Datos Estructurados (Schema.org)

<!-- JSON-LD: formato recomendado por Google -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "WebPage",
  "name": "Título de la página",
  "description": "Descripción",
  "url": "https://www.ejemplo.com/pagina"
}
</script>

5. Enlaces y Navegación

<!-- Favicon (obligatorio para identidad de marca) -->
<link rel="icon" type="image/x-icon" href="/favicon.ico">

<!-- Paginación: página siguiente y anterior -->
<link rel="next" href="https://www.ejemplo.com/pagina/2">
<link rel="prev" href="https://www.ejemplo.com/pagina/1">

6. Metadatos Opcionales pero Recomendados

<!-- Autor del contenido -->
<meta name="author" content="Nombre del autor">

<!-- Palabras clave (Google no las usa; Bing sí marginalmente) -->
<meta name="keywords" content="palabra1, palabra2">

<!-- Verificación de propiedad (Google Search Console, Bing Webmaster) -->
<meta name="google-site-verification" content="código-verificación">
<meta name="msvalidate.01" content="código-verificación">

Plantilla Completa Mínima Viable

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Título Optimizado | Marca</title>
  <meta name="description" content="Descripción de 150-160 caracteres con palabra clave principal.">
  <meta name="robots" content="index, follow">
  <link rel="canonical" href="https://www.ejemplo.com/pagina">
  <link rel="icon" href="/favicon.ico">

  <!-- Open Graph -->
  <meta property="og:title" content="Título Optimizado">
  <meta property="og:description" content="Descripción de 150-160 caracteres.">
  <meta property="og:url" content="https://www.ejemplo.com/pagina">
  <meta property="og:type" content="website">
  <meta property="og:image" content="https://www.ejemplo.com/og-image.jpg">

  <!-- Schema.org básico -->
  <script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "WebPage",
    "name": "Título Optimizado",
    "description": "Descripción",
    "url": "https://www.ejemplo.com/pagina"
  }
  </script>
</head>

Checklist de Implementación

Elemento Prioridad Observación
<title> Crítica Único por página. Máx. 60 caracteres.
<meta name="description"> Crítica Único por página. Máx. 160 caracteres.
<link rel="canonical"> Alta Obligatorio si existen duplicados o parámetros URL.
lang + charset Alta Configuración global del sitio.
Schema.org (JSON-LD) Media Según tipo de contenido: WebPage, Article, Product, etc.
Open Graph Media Esencial para compartir en redes sociales.
robots Baja Solo si necesitas restringir indexación.
Nota clave: Google ignora la etiqueta keywords. Enfócate en título, descripción, canonical y datos estructurados.

Aplicación en Todas las Páginas

Elemento ¿Cambia por página? Ejemplo
<title> ✅ Sí "Servicios de Diseño Web | Marca" vs "Contacto | Marca"
<meta name="description"> ✅ Sí Descripción específica del contenido de esa página
<link rel="canonical"> ✅ Sí URL absoluta de esa página
og:title, og:description, og:url ✅ Sí Datos específicos de cada página
Schema.org @type ✅ Sí WebPage, Article, Product, FAQPage, etc.
og:image ✅ Sí Imagen representativa de cada página
charset, viewport, lang ❌ No Globales, iguales en todo el sitio
favicon ❌ No Mismo archivo para todo el sitio
Recomendación práctica: Si tu sitio es estático (HTML puro), copia la plantilla base y modifica solo los campos variables en cada archivo. Si usas un framework o CMS, configura una plantilla dinámica que genere estos metadatos automáticamente según el contenido de cada página.
